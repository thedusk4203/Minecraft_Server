# Minecraft Server

AI-native Vietnamese-first Minecraft Survival SMP project.

## Product direction

The first release is a Java + Bedrock crossplay Survival SMP with economy, lightweight RPG progression, quests, PvE encounters, cosmetics and recurring live content. The MVP deliberately avoids splitting the community across multiple game modes.

## Current status

**Phase 0 — Product foundation.**

The next implementation milestone is Phase 1: a reproducible local technical skeleton with a Paper-compatible plugin, development database, Java/Bedrock crossplay proof, CI and automated test-server startup.

## Principles

1. Retention before feature count.
2. Player density before additional game modes.
3. Fair monetization before short-term revenue extraction.
4. Data durability and observability before scale.
5. AI agents implement and automate; consequential product and production decisions remain explicitly controlled.
